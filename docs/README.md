# docs — change log + decisions

One file per change in `changes/YYYY-MM-DD-slug.md`. Append one line to `CHANGELOG.md` per change.
Decisions (stack, schema) go in `decisions/ADR-###-*.md`.

Template for `changes/` files:
- Date, scope (backend/api/frontend), related commit
- What / why / how
- Files touched, API diff, migration notes
- How to verify + follow-ups
